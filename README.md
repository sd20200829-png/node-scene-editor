# Node Scene Editor

Ren'Py向けのノードベース シーンエディタです。ブラウザ上でシーンを視覚的に構成し、Ren'Pyプロジェクトへ直接出力します。

## 機能

- ノードの作成・接続・削除によるシーンフロー構築
- 背景動画・BGMのドラッグ&ドロップ割り当て
- 選択肢の追加・ドラッグ並び替え・ポート接続
- シーンプレビュー（動画・テキスト・選択肢の遷移確認）
- `scenes.json` + `script.rpy` の自動生成
- Ren'Pyプロジェクトフォルダへの直接保存・読み込み
- 未使用アセットの一括削除
- ノード自動整列・ミニマップ

## 使い方

### 1. エディタを開く

`editor/index.html` をChromium系ブラウザ（Chrome, Edge等）で開きます。

### 2. プロジェクトを選択

「プロジェクト変更」ボタンからRen'Pyのプロジェクトフォルダを選択します。
エディタは選択したプロジェクトの `game/` 配下に自動的にファイルを出力します。

### 3. シーンを編集

- 右クリック →「選択肢を追加」で新しいシーンノードを自動生成・接続
- 右クリック →「ゲーム終了を追加」で end_game ノードへ接続
- ポートをドラッグしてノード間を接続（入力・出力どちらからでも可）
- 動画・BGMファイルをノードにドラッグ&ドロップ
- 選択肢はドラッグで表示順を並び替え可能

### 4. 保存

「変更を保存」ボタンでプロジェクトに出力:

```
(プロジェクト)/game/
├── script.rpy          Ren'Pyスクリプト
├── scenes.json         シーンデータ
└── assets/
    ├── videos/         背景動画
    └── bgm/            BGMファイル
```

## 推奨ワークフロー

1. Ren'Pyランチャーでプロジェクトを新規作成（gui.rpy等が自動生成される）
2. エディタからプロジェクトフォルダを選択
3. エディタでシーンを構成・保存
4. Ren'Pyランチャーでテスト実行

## フォント

エディタが生成する `script.rpy` は起動時に `game/assets/fonts/` 内のフォントを自動探索します。
日本語表示には以下のいずれかを配置してください:

- `NotoSansJP-Regular.otf`
- `SourceHanSansJP-Regular.otf`
- `yomogi.ttf`
- `font.ttf` / `custom.ttf`

Ren'Pyランチャーで作成したプロジェクトに `gui.rpy` がある場合は、そちらでフォントを設定することも可能です。

## 推奨動画規格

- 形式: WebM（VP9 + Opus）
- 解像度: 1280x720 または 1920x1080
- フレームレート: 30fps

## 動作環境

- Chromium系ブラウザ（Chrome, Edge等）
  - File System Access API を使用するため Firefox / Safari は非対応
